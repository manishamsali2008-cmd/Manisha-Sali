# College Timetable and Task Planner

## Project Overview 
The College Timetable and Task Planner is a python - based project designed to help college students manage their academic timetable and task in an organized way. 

The project allows users to add and view timetable entries, manage academic task, update task status, and view an academic reports. 

## Features

- Add Timetable
- View Timetable
- Add Academic Task
- View Academic Tasks
- Update Task Status
- View Academic Rrport
- Input Validations

## Technologies Used

- Python
- Git
- Github


## Project Modules

- 'main_timetable.py' - Main program and menu
- 'timetable.py' - Timetable managemnet
- 'tasks.py' - Academic task managemnet
- 'trackingg.py' - Task status tracking
- 'report.py' - Task status tracking
- 'validation.py' - Input validation

## How to run

1. Install Python
2. Download or clone the project repository
3. Open the project folder in VS code
4. Run the following command:

python main_timetable.py

5. Select an option from the main menu.

## Main Menu

1. Add Timetable
2. View Timetable
3. Add Academic Task
4. View Academic Task
5. Update Task Status
6. View Academic Report
7. Exit
